Как сохранить список компаний в PDF
====================================

1. Откройте файл в браузере:
   Companies_List_VC_and_SaaS.html
   (двойной клик или перетащите в Chrome/Safari/Edge)

2. В браузере: File → Print (или Cmd+P / Ctrl+P)

3. В диалоге печати выберите принтер:
   "Save as PDF" (macOS) или "Save as PDF" / "Microsoft Print to PDF" (Windows)

4. Нажмите Save и укажите папку — получите файл .pdf

Файл уже свёрстан для печати (страницы, таблицы, шрифты).
