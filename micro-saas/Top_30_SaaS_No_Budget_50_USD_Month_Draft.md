# Топ 30 SaaS, которые можно запустить без бюджета (чек ~$50/мес)

**Черновик документа**  
Критерии: запуск с нулевым/минимальным бюджетом, целевая цена подписки около $50/месяц или возможность выйти на эту сумму с первых платящих клиентов.

---

## 1. Сервис напоминаний и follow-up по email/SMS
- **Суть:** Напоминания клиентам (врачи, тренеры, салоны) + шаблоны сообщений.
- **Почему без бюджета:** Ноу-код (Airtable + Make/Zapier) или простой бэкенд (Node/Python) + бесплатные тиры SendGrid/Twilio.
- **Чек:** $29–49/мес за 100–500 напоминаний.

## 2. Генератор контрактов и NDA под нишу
- **Суть:** Шаблоны договоров под одну нишу (фриланс, подряд, консультации) + простая кастомизация полей.
- **Почему без бюджета:** Статика + форма, PDF через библиотеку, оплата Stripe.
- **Чек:** $19–39/мес или разовые $9–29 за документ.

## 3. Чек-листы и онбординг для команд
- **Суть:** Чек-листы для онбординга, ревью проектов, закрытия спринтов. Шаринг по ссылке, галочки, дедлайны.
- **Почему без бюджета:** Supabase/Firebase + простой фронт, один разработчик.
- **Чек:** $29–49/мес за команду до 10 человек.

## 4. Агрегатор скидок и промокодов по нише
- **Суть:** Один сайт со скидками для одной ниши (например, софт для маркетологов, инструменты для дизайнеров). Партнёрские ссылки + ручное/полуавто обновление.
- **Почему без бюджета:** Статический сайт или простой CMS, монетизация партнёрками.
- **Чек:** Косвенно: $50/мес — реалистичный доход с рефералок при трафике.

## 5. Калькулятор стоимости под нишу (калькулятор смет, гонораров)
- **Суть:** Калькулятор для одной профессии (дизайн, разработка, копирайтинг) с сохранением расчётов и экспортом в PDF.
- **Почему без бюджета:** Фронт + лёгкий бэкенд для сохранения, без тяжёлой инфраструктуры.
- **Чек:** $19–39/мес или разовые расчёты по подписке.

## 6. Сервис опросов и мини-форм для событий
- **Суть:** Короткие опросы после вебинаров, митапов, воркшопов с экспортом в CSV и базовыми отчётами.
- **Почему без бюджета:** Формы + база (Supabase/Airtable), минимальный дизайн.
- **Чек:** $29–49/мес за организатора.

## 7. Трекер подписок и рекуррентных платежей (личный/микро-бизнес)
- **Суть:** Один пользователь или микробизнес: куда уходят деньги по подпискам, напоминания о продлении, базовые категории.
- **Почему без бюджета:** Простое приложение, без интеграций с банками (ручной ввод).
- **Чек:** $9–19/мес; $50/мес — суммарный доход с нескольких десятков пользователей.

## 8. Генератор контента под одну платформу (LinkedIn, Twitter, Telegram)
- **Суть:** Шаблоны постов + подсказки по формату и хештегам под одну платформу, без полноценного AI (или с бесплатным API с лимитом).
- **Почему без бюджета:** Статика + форма, опционально один AI endpoint с лимитом.
- **Чек:** $19–39/мес.

## 9. Сервис бронирования слотов (календарь) для одной ниши
- **Суть:** Календарь записи для консультантов, репетиторов, психологов: слоты, напоминания, одна ссылка.
- **Почему без бюджета:** Cal.com открытый код или свой минимальный бэкенд + календарь.
- **Чек:** $29–49/мес за специалиста.

## 10. Мини-CRM для одной воронки (лиды → сделка)
- **Суть:** Одна воронка: лид → квалификация → сделка. Без сложных ролей и отделов, для соло и микрокоманд.
- **Почему без бюджета:** Таблицы + статусы + email (Resend бесплатный тир), простой фронт.
- **Чек:** $39–59/мес; можно удержать «средний чек $50» пакетом.

## 11. Сервис хранения и шаринга паролей для малых команд
- **Суть:** До 5–10 человек: хранилище паролей с шифрованием, шаринг по ссылке с истечением, без корпоративных фич.
- **Почему без бюджета:** Шифрование на клиенте, бэкенд только для метаданных и ключей.
- **Чек:** $29–49/мес за команду.

## 12. Генератор отчётов из таблиц (один тип отчёта)
- **Сути:** Загрузка CSV/Excel → один тип отчёта (продажи, конверсии, активность) → PDF/ссылка.
- **Почему без бюджета:** Обработка на бэкенде, шаблон отчёта, без тяжёлой аналитики.
- **Чек:** $19–39/мес.

## 13. Сервис «найди дубли в списке» (контакты, домены, компании)
- **Суть:** Загрузка списка (email, телефоны, домены) → дедупликация и базовая нормализация.
- **Почему без бюджета:** Алгоритмы на своём коде, без дорогих внешних API.
- **Чек:** $29–49/мес или pay-per-use.

## 14. Лендинг + форма заявки под одну услугу
- **Суть:** Конструктор одного лендинга под одну нишу (услуга + форма + уведомление в Telegram/email).
- **Почему без бюджета:** Шаблоны, хостинг статики, serverless форма.
- **Чек:** $19–29/мес за один лендинг.

## 15. Трекер привычек и целей с напоминаниями
- **Суть:** Привычки/цели + напоминания в браузере/email, простые графики, без мобильного приложения.
- **Почему без бюджета:** PWA или веб, один стек, дешёвый хостинг.
- **Чек:** $9–19/мес; $50/мес — с небольшой базой платящих.

## 16. Сервис коротких опросов для NPS/удовлетворённости
- **Суть:** Один тип опроса (NPS или 1–5), встраивание на сайт, дашборд с базовой статистикой.
- **Почему без бюджета:** Виджет + API для ответов, простая аналитика.
- **Чек:** $29–49/мес за до 1–2k ответов.

## 17. Генератор сертификатов и благодарностей
- **Суть:** Загрузка списка имён + шаблон сертификата → генерация PDF и, опционально, отправка на email.
- **Почему без бюджета:** PDF на бэкенде, шаблоны, минимум хранилища.
- **Чек:** $19–39/мес или разовые пакеты.

## 18. Сервис «кто открыл письмо» для малого объёма
- **Суть:** Трекинг открытий и кликов для рассылок до 500–1000 писем/мес. Без полноценного email-маркетинга.
- **Почему без бюджета:** Resend/SendGrid + пиксель/редиректы, своя простая панель.
- **Чек:** $29–49/мес.

## 19. База шаблонов документов по одной отрасли
- **Суть:** Подписка на доступ к шаблонам (договоры, письма, инструкции) для одной отрасли с возможностью скачать и слегка править.
- **Почему без бюджета:** Контент + простой портал, Stripe подписка.
- **Чек:** $19–29/мес.

## 20. Калькулятор ROI/окупаемости для одной ниши
- **Суть:** Один тип расчёта (например, окупаемость рекламы, экономия на аутсорсе) с сохранением сценариев и экспортом.
- **Почему без бюджета:** Формулы на фронте/бэкенде, аккаунты, PDF.
- **Чек:** $29–49/мес.

## 21. Сервис напоминаний о днях рождения/датах (B2B или клубы)
- **Суть:** База контактов + даты (др, годовщины) → напоминания и готовые сообщения для отправки.
- **Почему без бюджета:** CRUD + кроны + email/SMS с бесплатными лимитами.
- **Чек:** $29–39/мес.

## 22. Агрегатор дедлайнов (гранты, конкурсы, подачи заявок)
- **Суть:** Один вертикальный агрегатор (например, гранты для НКО или дедлайны для стартапов) с подпиской на уведомления.
- **Почему без бюджета:** Ручной/полуавто контент, статика или простой бэкенд.
- **Чек:** $9–19/мес или реклама; $50/мес — суммарный доход.

## 23. Мини-складской учёт для одного типа товара
- **Суть:** Остатки + приход/расход для одного типа бизнеса (мерч, образцы, инструменты) без полного складского функционала.
- **Почему без бюджета:** Таблицы, роли, история, простой UI.
- **Чек:** $39–49/мес.

## 24. Сервис «визитка в одну ссылку» с аналитикой
- **Суть:** Одна страница: контакты, соцсети, кнопка «скачать vCard» + счётчик переходов по ссылке.
- **Почему без бюджета:** Статика + лёгкий бэкенд для счётчиков.
- **Чек:** $9–19/мес; $50/мес — с базы пользователей.

## 25. Генератор тестов и квизов для обучения
- **Суть:** Создание тестов/квизов с автоматической проверкой и простой статистикой по прохождениям (курсы, онбординг).
- **Почему без бюджета:** Редактор вопросов, прохождение, сохранение результатов.
- **Чек:** $29–49/мес.

## 26. Сервис очереди и талонов для одной точки
- **Суть:** Одна очередь (клиника, сервис, офис): запись в слот, уведомление «ваша очередь», без мультилокаций.
- **Почему без бюджета:** Слоты, статусы, Telegram/email.
- **Чек:** $29–39/мес за одну точку.

## 27. Трекер расходов по проектам/клиентам (микро-фриланс)
- **Суть:** Проекты + категории расходов + лимиты, отчёт за период. Для фрилансеров и микрокоманд.
- **Почему без бюджета:** CRUD, фильтры, экспорт.
- **Чек:** $19–29/мес.

## 28. Сервис «отзыв за бонус» (сбор отзывов с поощрением)
- **Суть:** Отправка ссылки на отзыв клиенту, фиксация отзыва, напоминание и бонус (скидка, баллы) после отзыва.
- **Почему без бюджета:** Ссылки, форма отзыва, интеграция с одной платформой отзывов или свой виджет.
- **Чек:** $39–49/мес.

## 29. Генератор прайс-листов и коммерческих предложений
- **Суть:** Шаблоны КП/прайсов под одну нишу, подстановка данных клиента и позиций, PDF на выходе.
- **Почему без бюджета:** Шаблоны, редактор полей, PDF.
- **Чек:** $29–39/мес.

## 30. Дашборд «все подписки в одном месте» (только метрики)
- **Суть:** Ручной ввод или API 2–3 сервисов (например, подписчики, доход, ключевые метрики) → один дашборд без глубокой аналитики.
- **Почему без бюджета:** Несколько источников данных, простые графики, без тяжёлого BI.
- **Чек:** $19–29/мес; $50/мес — пакет «pro» или накопленный доход.

---

## Как уложиться в «чек $50/мес»

- **Цена:** Делать тариф в зоне $19–49/мес или пакет ровно $49/мес как основной.
- **Без бюджета:** Использовать бесплатные тиры (Supabase, Vercel, Resend, Stripe без платы за старт), один стек, один разработчик, контент и поддержка своими силами.
- **$50 как цель:** Первые 1–3 платящих клиента по $19–49 уже дают «чек порядка $50/мес» в пересчёте на средний доход с продукта.

## Следующие шаги (для доработки драфта)

- [ ] Выбрать 3–5 идей под свой навык и нишу.
- [ ] Уточнить целевую аудиторию и каналы привлечения.
- [ ] Оценить минимальный MVP (функции за 2–4 недели).
- [ ] Зафиксировать стек и примерный месячный бюджет ($0 или до $50 на сервисы).
