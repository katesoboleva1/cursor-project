# Какой micro-SaaS запустить и каналы привлечения

Краткий выбор стартапа из [Tier 1](Top_30_SaaS_Market_Competitors_Test_Priority.md) и список каналов для первых клиентов.

---

## Какой стартап запустить (рекомендация)

Из Tier 1 выбраны **3 варианта** с конкретной нишей и быстрым MVP. Можно взять один и вести до первых платящих.

### Вариант 1 (приоритет): Генератор КП и прайс-листов под одну нишу

| | |
|---|---|
| **Что делаем** | Шаблоны коммерческих предложений и прайсов под одну отрасль. Клиент подставляет данные → получает PDF. |
| **Ниша для старта** | Например: **дизайн-студии и фриланс-дизайнеры** (РФ/СНГ или англоязычный рынок). Или: подрядчики/ремонт, консультанты, копирайтеры. |
| **MVP (2–4 недели)** | Лендинг + 3–5 шаблонов КП/прайса + форма полей + генерация PDF + Stripe ($19–29/мес или разовые). |
| **Почему сначала** | Чёткая боль («мне нужно КП»), один тип документа, легко объяснить и проверить спрос. |

---

### Вариант 2: Генератор контрактов/NDA под нишу

| | |
|---|---|
| **Что делаем** | Шаблоны договоров/NDA под одну сферу (фриланс, подряд, консультации). Заполнение полей → PDF. |
| **Ниша для старта** | **Фрилансеры в одной стране** (РФ, СНГ или англоязычные): дизайн, разработка, копирайтинг. |
| **MVP** | Лендинг + 2–3 шаблона (например, договор на услуги, NDA) + форма + PDF + оплата. |
| **Почему** | «Нужен договор под мою ситуацию» — частый запрос; узкая ниша снижает конкуренцию с DocuSign/PandaDoc. |

---

### Вариант 3: «Отзыв за бонус» для одной отрасли

| | |
|---|---|
| **Что делаем** | Сервис: отправка клиенту ссылки на отзыв → он оставляет отзыв → вы даёте бонус (скидка, баллы). Один тип интеграции (Google/Yelp/2GIS и т.п.). |
| **Ниша для старта** | **Салоны красоты, клиники, кафе** в одном городе или регионе. |
| **MVP** | Лендинг + создание ссылки на отзыв + фиксация «оставил отзыв» + напоминание + простая выдача бонуса (код/инструкция). |
| **Почему** | Понятная механика для малого бизнеса; можно тестировать на 5–10 заведениях. |

---

**Итог:** Запускать первым — **Вариант 1 (КП/прайсы)** или **Вариант 2 (контракты/NDA)**. Оба дают быстрый MVP, одну нишу и понятную монетизацию. Вариант 3 — если хочется уйти в офлайн-сервис (салоны, кафе).

## Каналы привлечения (где искать клиентов)

### Бесплатные / низкий бюджет

| Канал | Как использовать |
|-------|-------------------|
| **Product Hunt** | Запуск продукта; даёт трафик и обратные ссылки. Пример: Carrd — 10k пользователей за 24 часа. |
| **Telegram** | Канал по нише (не «про всё», а под боль: «КП и счета для дизайнеров»). Кейсы, разборы ошибок, шаблоны. Участие в чатах и каналах ЦА (фриланс, дизайн, подряд). |
| **Reddit** | Сабреддиты по нише (r/freelance, r/smallbusiness, r/design, r/Entrepreneur и т.д.). Отвечать на вопросы, давать пользу; в профиле — ссылка на продукт. Не спамить. |
| **LinkedIn** | Посты про боль ниши («Почему КП дизайнера выглядят непрофессионально»), кейсы, короткие советы. Комменты в постах целевой аудитории. Поиск по должностям (например, «владелец дизайн-студии»). |
| **Хабр / VC.ru** | Статьи и посты: как считать КП, какие ошибки в договорах, как собирать отзывы. В конце — мягкий CTA на инструмент. |
| **Indie Hackers** | «Building in public», обсуждение продукта, обмен опытом. Аудитория — основатели и первые пользователи. |
| **Hacker News** | «Show HN: [ваш продукт]» — для технической и стартап-аудитории. Подходит под B2B/инструменты. |
| **SEO + контент** | Статьи под запросы ниши: «шаблон КП для дизайнера», «как составить договор на дизайн», «как просить отзывы у клиентов». Блог на сайте + гостевые посты на отраслевых площадках. |
| **Комьюнити (Slack, Discord)** | Чаты по фрилансу, дизайну, малому бизнесу. Быть полезным, потом упоминать продукт по запросу. |

### Платные (после валидации)

| Канал | Как использовать |
|-------|-------------------|
| **Таргет (Meta, VK)** | Небольшие бюджеты ($50–100) на тест: лендинг + «получить шаблон КП» или «попробовать бесплатно». Сегмент: фрилансеры, владельцы малого бизнеса, по интересам. |
| **Яндекс.Директ / Google Ads** | Ключевые запросы: «коммерческое предложение шаблон», «договор на услуги фрилансер», «как собрать отзывы клиентов». Малая ставка, проверка конверсии. |
| **Реклама в Telegram** | Покупка постов/упоминаний в каналах вашей ниши. Выбирать каналы с живой аудиторией и адекватной ценой за охват. |

### Партнёрства и прямые контакты

| Канал | Как использовать |
|-------|-------------------|
| **Партнёры** | Бухгалтеры, юристы, маркетологи, работающие с фрилансерами и малым бизнесом. Обмен рекомендациями или % с продаж. |
| **Прямые сообщения** | 50–100 человек из ЦА (LinkedIn, Telegram, email): короткое сообщение с болью + ссылка на лендинг или демо. Цель — отклики и первые платящие. |
| **Лендинг + лид-магнит** | Бесплатный шаблон КП или чек-лист «Как не облажаться с договором» в обмен на email. Дальше — серия писем и предложение платного продукта. |

## Порядок действий (кратко)

1. **Выбрать один стартап** из трёх (рекомендация: КП/прайсы или контракты/NDA) и **одну нишу** (например, дизайн-фриланс в РФ).
2. **Сделать MVP:** лендинг + основная функция (генерация PDF или контракт) + оплата или лид-форма.
3. **Валидация до сборки:** лендинг + «записаться в список» или «получить демо»; рассылка 30–50 людям из ЦА (Telegram, LinkedIn). Если есть отклики — достраивать продукт.
4. **Запуск:** Product Hunt, пост в Telegram/Reddit/LinkedIn/Хабр с историей и ссылкой.
5. **Постоянно:** контент (SEO, посты), участие в комьюнити, партнёры и прямые контакты. Платные каналы подключать после первых продаж.
