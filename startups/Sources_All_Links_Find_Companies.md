## Как пользоваться

1. **Портфели (Antler, YC, Seedcamp, EF и т.д.):** открываешь → фильтруешь по Location (Cyprus, Europe, UK) и Sector → копируешь названия компаний → ищешь founder/HR в LinkedIn по названию.
2. **Job-борды:** фильтр по роли (PM, BD, Operations), локации и "relocation"/"visa" где есть → отклик + дубль сообщением фаундеру в LinkedIn.
3. **Базы (Crunchbase, Dealroom, VCBacked):** фильтр Headquarters = Cyprus или Europe, Employee count = 1–50, Funding = Seed/Series A → экспорт или ручной список → LinkedIn.
4. Сохраняй найденные компании в свою таблицу (компания, контакт, дата, статус), как в гайде по поиску.

## Автоматический парсинг (скрипт)

Запуск из корня проекта:
```bash
python3 startups/fetch_companies_from_sources.py
```

- **YC:** берёт hiring-компании с team 1–50 из API (https://yc-oss.github.io/api/companies/hiring.json) или из локального `startups/yc_hiring.json`. Результат: `Parsed_Companies_From_Sources.csv` и `.md`.
- **Antler / TechIsland:** на этих сайтах список компаний подгружается через JavaScript, обычный HTTP-запрос возвращает пустой контент. Чтобы их спарсить, нужен headless-браузер (Playwright/Puppeteer) или ручной экспорт по ссылкам выше.
- **Остальные источники** (Seedcamp, EF, Relocate.me, Crunchbase, Dealroom и т.д.) — публичного API нет, только ручной просмотр или платные/скраперные решения.
