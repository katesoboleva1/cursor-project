## 3. Списки маленьких стартапов (куда реально пролезть)

Маленькие команды = проще попасть на EA/BD, меньше формального отбора.

| Ресурс | Ссылка | Что даёт |
|--------|--------|----------|
| **YC — директория компаний** | https://www.ycombinator.com/companies | 5000+ стартапов; фильтр по batch, размеру, гео, индустрии. Маленькие = ранние батчи, 1–50 человек |
| **YC — Work at a Startup** | https://www.workatastartup.com/ | Вакансии именно в YC-стартапах (часто seed/Series A) |
| **YCDB (YC Database)** | https://www.ycdb.co/ | Неофициальная база YC: рейтинги, размер, funding — удобно фильтровать «маленькие» |
| **Seedcamp — портфолио** | https://seedcamp.com/our-companies/ | 550+ компаний, фильтр по году и индустрии; много маленьких |
| **LocalGlobe — портфолио** | https://localglobe.vc/portfolio/ | Ранние стадии, UK/EU |
| **Point Nine — портфолио** | https://www.pointnine.com/portfolio | B2B SaaS, marketplaces; маленькие команды |
| **Cherry Ventures — портфолио** | https://www.cherry.vc/portfolio | EU, seed |
| **Backed — портфолио** | https://backed.vc/portfolio | UK/EU, ранние стадии |
| **Wellfound — компании** | https://wellfound.com/companies | Стартапы с вакансиями; фильтр по размеру и стадии |
| **Otta — компании** | https://app.otta.co/companies | UK/EU; можно смотреть по размеру компании |
| **Dealroom — стартапы** | https://app.dealroom.co/ (или dealroom.co) | Фильтр: стадия (seed, Series A), гео, размер — экспорт или ручной список |
| **Crunchbase — компании** | https://www.crunchbase.com/search/organizations | Фильтр: последний раунд seed/Series A, Location UK/US/EU, размер команды |
| **VCBacked — по фонду** | https://www.vcbacked.co/directory/investors | Выбрать фонд → список портфолио-компаний |
| **Wikipedia — YC стартапы** | https://en.wikipedia.org/wiki/List_of_Y_Combinator_startups | Список по годам (для идей названий) |

**Как пользоваться:** заходи в портфолио 2–3 фондов (например Seedcamp + Point Nine + LocalGlobe), выписывай по 10–20 компаний с сайта/LinkedIn, проверяй размер команды (LinkedIn → Company → About). Те, где 10–80 человек — те самые «маленькие», куда проще пролезть.

## Кратко по разделам

- **Работа:** LinkedIn Jobs, Wellfound, Otta, Work at a Startup (YC).
- **Фонды:** Dealroom (в т.ч. uk.dealroom.co), Crunchbase Discover (investors), прямые страницы Team на сайтах фондов.
- **Маленькие стартапы:** YC Companies + Work at a Startup, портфолио Seedcamp, LocalGlobe, Point Nine, Cherry, Backed; Wellfound/Otta по компаниям с фильтром по размеру.

Все ссылки рабочие на момент составления; если что-то переехало (например Otta → Welcome to the Jungle), домен может сохраняться (otta.co).
